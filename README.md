# Tooodo

**解锁手机之前，先看一眼还有什么没做。**

Tooodo 是一个把未完成待办放在锁屏上的待办应用。每次亮屏，还没解锁，今天要做的事就已经摆在眼前，不用专门打开应用，也不会忘。

## 功能

- **锁屏提醒**：亮屏时直接在锁屏上列出未完成的待办，点一下就能完成，解锁后自动消失。全部做完就不再打扰。
- **安排日期**：待办默认是今天，也可以一键排到明天、后天，或在日历里选任意一天。到了那天会自动出现在「未完成」里。
- **周期任务**：每天，或每周固定几天，比如「每周一、三健身」，每天各自打勾。
- **不会漏掉**：以前没做完的事会归到「历史任务」，锁屏上继续提醒，直到做完或清空。
- **随手修改**：点一下待办就能改内容和日期，误删可以马上撤销。
- **复制和分享**：长按多选，一键复制，或分享到微信发给别人。
- **应用内更新**：在设置里检查更新，下载安装一步到位。

## 下载

在 [发行版](https://gitee.com/qqinling/tooodo/releases) 下载最新的 APK 安装，支持 Android 8.0 及以上。

小米、华为、OPPO / realme、vivo 等手机，请在应用详情里允许「自启动」和「后台弹出界面」，锁屏提醒才能稳定出现。vivo / iQOO 还需要在 设置 → 电池 → 后台耗电管理 里把 Tooodo 设为「允许后台高耗电」，否则系统会冻结它，亮屏时不弹提醒。
