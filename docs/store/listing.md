## 应用介绍

Tooodo 是一个把未完成待办放在锁屏上的待办应用。

每次点亮屏幕，还没解锁，今天要做的事就已经摆在眼前。不用专门打开应用，也不会忘。

【锁屏提醒】亮屏时直接在锁屏上列出未完成的待办，点一下就能完成，解锁后自动消失。全部做完就不再打扰。
【安排日期】待办默认是今天，也可以一键排到明天、后天，或在日历里选任意一天，到了那天会自动出现。
【周期任务】支持每天，或每周固定几天，比如「每周一、三、五健身」，每天各自打勾。
【不会漏掉】以前没做完的事会归到「历史任务」，锁屏上继续提醒，直到做完或清空。
【随手修改】点一下待办就能改内容和日期，误删可以马上撤销。
【复制和分享】长按多选，一键复制，或分享给别人。

【隐私】待办只保存在手机本地，没有账号，不联网，不接入任何统计、广告或第三方 SDK。

提示：为了在锁屏上稳定显示提醒，请在应用详情中允许「自启动」「后台弹出界面」和「锁屏显示」。

## 敏感权限用途（审核表单里「权限说明」逐条填写）

| 权限 | 用途 |
|---|---|
| 悬浮窗 SYSTEM_ALERT_WINDOW | 亮屏时在锁屏上显示未完成的待办，这是应用的核心功能 |
| 通知 POST_NOTIFICATIONS | 显示常驻通知保持提醒服务运行；悬浮窗无法弹出时用通知显示提醒 |
| 全屏通知 USE_FULL_SCREEN_INTENT | 提醒界面无法直接弹出时的备用显示方式 |
| 前台服务 FOREGROUND_SERVICE_SPECIAL_USE | 常驻服务监听「屏幕点亮」广播（该广播只能动态注册） |
| 开机自启 RECEIVE_BOOT_COMPLETED | 重启或更新后恢复锁屏提醒 |
| 精确闹钟 USE_EXACT_ALARM | 提醒服务被系统结束后 1 秒内重启它 |
| 忽略电池优化 REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | 仅在用户点击设置中的按钮时申请，避免被省电策略冻结 |

## 审核测试说明（如有「给审核人员的备注」一栏）

无需账号。打开应用 → 同意隐私政策 → 输入一条待办并添加 → 按电源键熄屏再亮屏，锁屏上会显示未完成的待办。也可以在 设置 → 预览锁屏提醒 里直接查看。
